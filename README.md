# README：下一次 session 从这里开始

> 在线网站：https://derekham.github.io/Chinese-Paper-2-Revision/

这个文件夹是《日出》与《太阳照常升起》的比较阅读资料库。已经做过的事情主要有三件：把两篇原文全文分成了 255 段并加了标签，整理了一份按论文论点走的例证路线，另外还有一份比较详细的文学分析规范。

这份 README 不是给读者看的“项目介绍”，而是给之后的 session 用的工作说明：**先看什么、怎么找材料、写的时候守哪些底线、什么时候该回到原文和参考文献。**

---

## 一、每次开始时的顺序

不用一次把所有文件读完。建议按下面的顺序，读到够用就停。

1. **先看这份 README**，知道文件夹里有什么、这次任务大概要走哪条路。
2. **看 `INDEX.md`**，它是总导航；如果任务很明确，直接跳到第 3 步。
3. **看 `文本索引/05_Paper2_例证路线.md`**。这里已经按三个论点（太阳/得救、钱、女人被看）和五个比较点，把两篇作品的关键段号、行号、原文内容排好了。大多数“帮我找例子”“帮我比较”的任务，从这份文件开始最快。
4. **读 `literary_analysis_guidelines.md`**。至少读第 3、4、5、6、7、8、9 节。它不是格式模板，而是判断标准：什么叫文本证据、什么叫过度解读、比较怎么做、资料怎么记。
5. **按段号回到 `文本索引/01_...` 或 `02_...`**，看该段的摘要、引文和标签；如果摘要不够，再按行号回到 `日出.txt` / `太阳照常升起.txt` 读上下文。
6. **只有任务需要时才看 `参考文献/`**。不要为了显得有学术感而先翻文献；先知道自己要解决什么问题，再去找对应的资料。

一句话：**索引负责“去哪里找”，规范负责“怎么判断”，原文负责“到底怎么写”，参考文献负责“别人怎么谈”。四者不要互相代替。**

## 三、怎么用索引，才不浪费时间

### 1. 先查 05，再查 03

`文本索引/05_Paper2_例证路线.md` 是“已经替你走过一遍”的路线：它告诉你哪个段最能支撑哪个论点。`文本索引/03_标签反查表.md` 是“补充搜索”：比如 05 里某个论点只列了五六段，你可以再搜 `金钱/账单`、`女性/被看`、`舞台说明`，看有没有漏掉的例子。

不要一上来就把 `01`、`02` 从第一段读到第二百五十五段。索引的意义就是让你**只读需要的那几段**。

### 2. 段号、行号怎么用

每段开头都长这样：

```markdown
### R4-29｜L5048–L5065｜“太阳不是我们的”：白露躲进卧室，方达生独白
```

- `R4-29` 是段号，`R` 代表《日出》，`4` 是第四幕；`S1-04-05` 代表《太阳》第一部第四章第 5 段。
- `L5048–L5065` 是原文行号。要看上下文，用 `read` 的 offset/limit，或：

```bash
sed -n '5040,5072p' 日出.txt
```

- 索引里的“摘要”只是导航，不是论文句子。引用一定回原文，按原文逐字抄。

### 3. 标签是“可能相关”，不是“标准答案”

一段可以同时有 `太阳/天亮`、`陈白露`、`舞台说明`、`核心例证` 四个标签，这很正常。标签多不代表这段一定最重要；它只表示“如果你在找这些主题，值得看一眼”。

`核心例证` 这个标签贴得比较宽（255 段里约 140 段），所以找论文例子时，**先用 05 的路线，再用 `核心例证` 补充**，不要反过来。

### 4. 索引和原文冲突时，以原文为准

索引是二手整理，可能有概括偏差；原文才是最终依据。尤其是《日出》的网络整理本，个别字词可能有 OCR 讹误；《太阳》是赵静男译本，讨论语言时要分清“译文这样写”和“英文原文这样写”。

另外，索引是导航工具，不是学术来源。论文正文不要写“根据文本索引……”，只能引原文，或引真正读过、核对过的二手资料。

### 5. 出处标签可以直接跳回原文

网站入口：

**https://derekham.github.io/Chinese-Paper-2-Revision/**

索引和分析文档里的 `L5046`、`第 51 页` 都是链接，指向同一个阅读器：

```text
viewer.html?w=r&l=5046       《日出》第 5046 行
viewer.html?w=r&p=51         《日出》第 51 页
viewer.html?w=s&l=7418       《太阳》第 7418 行
viewer.html?w=s&p=208        《太阳》第 208 页
```

- `w=r` 是《日出》，`w=s` 是《太阳照常升起》。
- `l=` 是行号，`p=` 是页码。
- 阅读器只保存一份 txt，用 JS 在浏览器里生成行号；**加引用不会增加网站文件大小**。
- md 和 docx 里用完整网址；Word 打开的是真正的 HTTP 页面，不会再丢锚点。

本地预览：

```bash
python3 -m http.server 8000 --directory docs
# 打开 http://localhost:8000/viewer.html?w=r&l=5046
```

改完 txt 或 md 后重新生成网站：

```bash
python3 _build_site.py
```

站点输出在 `docs/`；GitHub Pages 从 `docs/` 发布。`日出.txt` 的页码映射在 `文本索引/页码映射_日出.tsv`，`太阳照常升起.txt` 的页码直接读 `【第 N 页】`。

## 四、写分析时守住的几条底线

这一节是 `literary_analysis_guidelines.md` 的浓缩版。真正动笔前，还是建议读原文件的相关章节。

还有一条默认原则：**不要默认用户需要一篇完整成文的论文。** 用户可能只是在收集材料、检查一个想法、建立证据库。先判断这次到底要什么，再决定输出多长。缺少版本、片段或题目时，只有在这会实质影响分析时才问；否则先说明采用的假设，尽力完成。

### 1. 先文本，后解释

不要先有一个“主题”，再找几句话来凑。先看：这个场景里谁在做什么、说了什么、灯光/声音/空间怎么安排；然后才问“这让人注意到什么”。

### 2. 观点—证据—解释，三步都要有

只写“作者用了对比手法”不算分析。要说清：对比的双方是谁、差异在哪里、这个差异让读者/观众看到什么。

只贴一句引文也不算分析。引文后面要解释：这句话在这个场景里起什么作用，和人物、结构、结尾有什么关系。

### 3. 区分文本事实、合理解读、推测

- **文本事实**：作品明确写出的台词、动作、舞台说明、叙述。
- **合理解读**：有具体细节支持，但可能有别的解释。
- **推测**：证据不足，需要作者背景、历史资料、版本信息才能确认。

不要把后两种说成第一种。可以用“这可能暗示”“一种合理的理解是”“文本没有明确说明”来标记判断的强度。

### 4. 比较要围绕一个问题，不要写成两篇简介

不要先写一大段《日出》，再写一大段《太阳》，最后补一句“两者都……”。比较段应该围绕同一个问题组织：比如“天亮时人物在哪里”“钱怎样被说出来”“女人的形象由谁叙述”。

每一个比较点，最好两边都有具体证据。不要一边分析得很细，另一边只顺带提一句。

### 5. 不要把人物当作者的传声筒

方达生说的不等于曹禺说的；杰克说的不等于海明威说的；舞台说明也不等于“作者完全赞同的判断”。分析时区分作者、叙述者、人物和作品呈现出的观点。

### 6. 不要诊断人物，不要堆术语

可以说“她的语气很疲惫”“他反复回避这个问题”，不要说“她有抑郁症”“他是典型的创伤后应激障碍”。除非有可靠的文本外资料，否则不要给人物做临床诊断。

术语要用得准、用得上。不要为了显得深刻，堆“解构、异化、主体性、空间政治”这类词。普通语言能说清楚，就用普通语言。

### 7. 引文必须逐字，找不到就说找不到

不要把自己的概括放进引号里。不要编造页码、章节、台词、情节或作者背景。不确定时标注“待核对原文”，或者先用情节概述代替直接引用。

索引里的 832 条引文已经用脚本核对过，能在标注行找到；但你正式引用前，仍建议回原文看一眼上下文。

### 8. 结尾要说出“比较后多知道了什么”

不要只总结“二者既有相同点也有不同点”。要回答：把这两处放在一起，我对“太阳/钱/女性/形式”的理解多了什么？这个差别说明什么？

## 五、参考文献怎么用

`参考文献/` 里有 6 份 PDF：

- `Studies_of_Cao_Yu_Chinese_Performing_Arts_2020.pdf`
- `The_Awakening_of_Modern_Chinese_Women_from_Cao_Yu_Plays_2026.pdf`
- `The_Influence_of_Christian_Culture_on_Modern_Chinese_Literature_2023.pdf`
- `The_Sun_Also_Rises_A_Portrait_of_the_Lost_Generation_2025.pdf`
- `戏剧评论与日出经典化生成_2024.pdf`
- `曹禺戏剧叙事理论探究_李文英_2017.pdf`

### 1. 先记录“读到什么程度”

`Paper2_研究资料_日出_太阳照常升起.md` 的第 7 节已经标了每份资料的阅读状态：全文、摘要、二手引文、篇名/目录。这个标注很重要。

- 只读了摘要，就说“据摘要”，不要说“这篇论文认为……”然后展开得像读过全文。
- 只通过别人的文章知道某个观点，就说“转引”，不要假装读过原书。
- 没查到页码、DOI、出版信息，就写“未查到”，不要补造。
- PDF 可以直接用 `read` 打开；如果是扫描版、提取不出文字，先用 `pdftotext` 试试，或者只依据能读到的摘要/章节，不要假装读过全文。

### 2. 文献是“支持/对照”，不是论文主体

论文的主体仍然是你对两处文本的具体比较。二手资料可以用来：

- 提供一个背景或批评史的位置；
- 支持一个你已经在文本里看到的趋势；
- 提供一个相反的解释，让你说明自己为什么不完全同意。

不要大段照搬摘要，也不要把某篇论文的结论硬拼成“两作相似”的结论。

### 3. 引用格式

中文资料至少写：作者、篇名、期刊/书名、年份、页码（有就写）。英文资料至少写：作者、篇名、期刊/书名、卷期、年份、页码、DOI（有就写）。

如果只读到摘要，引用时注明“据摘要”；如果是转引，注明“转引”。具体例子可以看 `Paper2_研究资料_日出_太阳照常升起.md` 第 8.3 节。

### 4. 版本和翻译

- 《日出》有 1936 年初版和 1951 年修订版，人物和部分内容不同。写论文时注明你依据的版本；网络整理本只能作为工作文本，正式引用尽量核对纸本或《曹禺全集》。
- 《太阳照常升起》是赵静男译本（上海译文出版社 2011 年版）。讨论“海明威的语言”时，要区分译文和英文原文；比如结尾的 “Isn’t it pretty to think so?” 译成“这么想想不也很好吗”，反讽的强度就不完全一样。

## 六、常见任务怎么起手

### A. “帮我整理某个人物”

1. 在 `文本索引/03_标签反查表.md` 搜人物名，得到段号。
2. 先读该人物第一次出场、最关键的三四场戏、结尾。
3. 建一张表：场景/段号 → 原文证据 → 人物说了什么/做了什么 → 别人怎么评价 → 可以怎么解释 → 证据强度。
4. 回原文核对引文，尤其是长台词。

不要只列“善良/懦弱/复杂”这类标签；每个判断都要有具体言行。

### B. “帮我比较两篇作品的某个点”

1. 先看 `文本索引/05_Paper2_例证路线.md` 有没有现成路线。
2. 如果没有，围绕一个具体问题，各找 3—5 段。
3. 用“同一个问题 → A 怎么写 → B 怎么写 → 差别说明什么”的结构，不要先完整总结 A 再完整总结 B。
4. 注意形式差异：话剧有舞台说明、灯光、声音、空间；小说有第一人称、省略、语气。

### C. “帮我找文献/背景”

1. 先看 `Paper2_研究资料_日出_太阳照常升起.md` 第 7 节有没有已经整理过的资料。
2. 再看 `参考文献/` 里的 PDF 标题，判断哪一份和问题最相关。
3. 读摘要/相关章节，记录：作者、篇名、出版信息、核心观点、能支持哪个文本观点、局限。
4. 明确标注阅读状态。不要把“标题看起来相关”写成“这篇研究了……”。

### D. “帮我改这段文字”

1. 先读 `literary_analysis_guidelines.md` 第 10 节 G。
2. 优先保留用户的原意、观点和表达习惯；不要擅自改成“更成熟、更华丽”的语言。
3. 除非用户要求重写，否则先指出问题，再给局部修改建议；最好展示原句和修改句，说明改了什么。

### E. “这个解释成立吗？”

不要为了迎合而一味说“成立”。先看证据够不够、逻辑有没有跳步、有没有反例。如果不成立，直接说问题在哪里，同时保留其中可以继续发展的部分。

## 七、输出和文件约定

- 新写的分析、人物整理、比较表，放在根目录或 `文本索引/` 之外，用清楚的中文文件名，例如 `人物_陈白露_证据表.md`、`比较_太阳与天亮.md`。
- 不要覆盖用户已有的 docx/md；需要改的时候先读一遍，确认哪些是用户自己的内容。
- 不要修改 `日出.txt`、`太阳照常升起.txt` 的原文。索引可以改，原文不动。
- 如果新增了分段，或调整了行号：
  1. 在对应的 `01`/`02` 索引里加段，保持段号连续；
  2. 运行 `cd 文本索引 && python3 _build_tag_index.py`，更新 `03`、`04`；
  3. 运行 `python3 _check_quotes.py`，确认引文还能在原文找到。
- 如果重跑 `_merge_index.py`，页码行会从 `_分段原稿/` 保留；合并后再运行 `_build_tag_index.py`，让 `03`、`04` 同步页码。
- 如果只是写分析、不新增分段，不需要动索引；可以把新文件加到 `INDEX.md` 的“已有论文资料”表里。
- 引用格式统一带段号、行号和页码，例如：`（《日出》R4-29，L5046，第 51 页）`、`（《太阳照常升起》S3-19-13，L7418–L7425，第 208 页）`。这样下一个 session 能直接回到原文。
- 新写的 md 也尽量用可点击标签：`[L5046](https://derekham.github.io/Chinese-Paper-2-Revision/viewer.html?w=r&l=5046)`、`[第 208 页](https://derekham.github.io/Chinese-Paper-2-Revision/viewer.html?w=s&p=208)`。

### 页码标注（硬性要求）

- **凡引用《太阳照常升起》的例证，必须同时给页码。** 索引、例证路线、意象整理、人物整理、场景整理，以及导出的 docx，都不要只写章次或段号。
- 页码来源是 `太阳照常升起.txt` 里的 `【第 N 页】` 标记（上海译文出版社 2011 年版 PDF 页序）。格式：`（《太阳照常升起》S1-04-05，L982–L1090，第 39–41 页）`；单页写 `第 208 页`，跨页写 `第 39–41 页`。
- 《日出》页码按 `01_日出_分段索引.md` 的网页页序（`01.htm`–`51.htm` 为第 1–51 页，`00.htm` 的序记作“序页”）。格式：`（《日出》R4-29，L5046，第 51 页）`。
- 如果一段引文暂时只有章次或段号、没有行号，先按原文定位行号，再补页码；**不要凭印象写页码**。找不到确切页码时，写“待核对原文”，不要编造。

## 八、这份 README 可以更新

这份 README 是工作说明，不是固定不变的规章。**用户提出要求时，之后的 session 可以更新它。**

更新时请遵守几条：

1. **先读现有内容**，不要凭印象重写。
2. **只改需要改的部分**。如果只是新增一个文件，就在文件表里加一行；不要顺便把整篇改成另一种风格。
3. **保留仍然有效的约定**。除非用户明确说“这条不要了”，否则不要删除“引文核对”“区分文本/解读/推测”“不伪造文献”这些底线。
4. **在文末 changelog 记一笔**：日期、改了什么、为什么改。
5. **不要为了记录而记录**。一次性的任务结果不用写进 README；只有工作流程、文件结构、协作约定发生变化时才更新。
6. 如果用户的要求和这份 README 冲突，**以用户这次的要求为准**，但可以在 changelog 里说明这次为什么破例。
